Every tool that reads, predicts, or renders Minecraft world data, lined up next to Sojourner — grouped by what they actually are, because "map viewer" means five different things depending who's selling it. No score being kept, just an honest table.

"Seed-ahead prediction" and "map built by exploring" are different products wearing the same word — a seed tool describes a world that doesn't exist yet; a minimap describes only what you've walked past. Sojourner does both — predicted seed data and the real save, on the same map — which is why it doesn't sort cleanly into either category above.
Reading the gaps

What's worth a look

Not every dash above is a missing feature — some of these are just different products (a live multiplayer server map and a local single-save viewer solve different problems). These are the dashes that actually sting:

  • 3D view. BlueMap renders full 3D terrain in-browser; Amulet's editor viewport is 3D too. Sojourner is 2D top-down only (plus the cave-mode depth slice). A real gap if "explore in 3D" ever becomes a goal — a large one, not a quick add.
  • Java ↔ Bedrock conversion. Chunker and Amulet both convert a world between formats. Sojourner reads both editions but has no write-path between them — out of scope today, but worth naming as a capability nobody's asked for yet.
  • General world editing. Amulet and NBT Studio let you edit anything, anywhere. Sojourner's write path is narrowly structure copy/paste, and still dev-build-gated pending backup/restore (see project_structure_copy_paste memory). Expanding that is a deliberate, gated decision, not a gap to close casually.
  • Live, in-the-moment exploration. Xaero's, JourneyMap, and SeedMapper's minimap all update while you play, in-game. Sojourner is a separate desktop app you tab out to — a real UX difference, but also the tradeoff that makes the deep chest/entity/loot inspection possible at all in the first place.
  • Standalone-without-a-save 3D screenshots. Chunky's path-traced renders are a different value prop entirely (marketing/cinematic shots vs. functional map) — not a gap, just a non-goal.

Nobody else on this list does all of it at once — real block colors, seed prediction, structure loot, container contents, entity depth, and ore veins, on both editions. That's the actual pitch. The gaps above are real; just don't let them drown that out.
